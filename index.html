Questions before you download.

Is RelayPad really free?

Yes. It is free for personal use, with no ads, no account and no trial period.

Windows warns about the installer. Is it safe?

RelayPad is new and its installer is not code signed yet, so Windows SmartScreen may say "unknown publisher". Choose More info, then Run anyway. Updates are signed, and the app checks that signature before installing one.

Which games work?

Any game that supports an Xbox 360 or DualShock 4 controller, which covers almost every PC game with gamepad support, on Steam or anywhere else.

Will games see two controllers?

They can. Install the optional HidHide driver from Settings, Drivers, and games only see the RelayPad controller. On Switch 2 controllers this is still being tested.

Do I need Bluetooth?

Not always. The Switch 2 Pro Controller and the Switch Pro Controller work over a USB cable. Joy-Con 2 have no USB port, so they need a Bluetooth adapter.

Can I use several controllers at once?

Yes, up to eight, each on its own player. You can move a controller to another player or swap two of them from the app.

Does it send my data anywhere?

No. RelayPad can keep a diagnostic report on your PC if you allow it on first run. Nothing is uploaded.

How do I uninstall it?

From Settings, Apps, Installed apps in Windows. Drivers you added from RelayPad are removed from its own Drivers page.
